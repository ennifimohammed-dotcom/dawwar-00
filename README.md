# 🤝 دوّار - تطبيق إدارة الجمعيات المالية

تطبيق Flutter لإدارة الجمعيات (الدوّار) بطريقة احترافية وسهلة.

## ✨ المميزات

- ✅ إنشاء جمعيات شهرية أو أسبوعية
- ✅ إدارة الأعضاء مع ترتيب الدور تلقائياً
- ✅ توليد الدفعات تلقائياً لكل عضو
- ✅ تتبع حالة الدفع (دفع / في الانتظار / متأخر)
- ✅ إحصائيات لحظية للجمعية
- ✅ مشاركة تقرير الجمعية عبر واتساب
- ✅ واجهة عربية كاملة RTL
- ✅ تصميم مغربي أنيق

## 🚀 تشغيل المشروع

```bash
flutter pub get
flutter run
```

## 📱 بناء APK

```bash
flutter build apk --release
```

أو من خلال GitHub Actions تلقائياً عند رفع الكود.

## 🏗️ هيكل المشروع

```
lib/
├── core/
│   └── theme/          # الألوان والتصميم
├── data/
│   ├── database/       # SQLite
│   └── models/         # النماذج
└── presentation/
    ├── providers/       # إدارة الحالة
    ├── screens/         # الشاشات
    └── widgets/         # المكونات
```

## 🔧 التقنيات

| التقنية | الاستخدام |
|---------|-----------|
| Flutter | إطار العمل |
| SQLite (sqflite) | قاعدة البيانات المحلية |
| Provider | إدارة الحالة |
| share_plus | مشاركة التقارير |

## 📂 GitHub Actions

يتم بناء APK تلقائياً عند كل push على `main`.
نزّل الـ APK من: **Actions → Artifacts → dawwar-release-apk**
